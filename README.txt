SPEECH COACH - Risha's Frontend

This version includes the current frontend design changes:
- Light / Dark mode toggle
- Microphone image beside the Speech Coach title
- #219DBC medium teal-blue for primary actions
- #92C9E6 light sky-blue outlines for analysis cards
- Ring-style Delivery Factors / Improvement Tracker
- Red / Yellow / Green score rings
- Audio upload and browser microphone recording
- Transcript with filler-word highlighting
- Feedback section

IMPORTANT:
The current /analyze endpoint still uses demo results. The real Sinchana,
Prakruthi and Ananya modules will be connected later.

RUN:
1. Open Command Prompt in this folder.
2. Run: py -m pip install -r requirements.txt
3. Run: py app.py
4. Open: http://127.0.0.1:5000
